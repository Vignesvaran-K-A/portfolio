### Hey there! I'm Vignesvaran 👋

I'm a developer interested in building **practical, scalable and intelligent software systems**.

My projects bring together data engineering, artificial intelligence, connected devices and software development. I enjoy exploring how raw data can become useful information, how AI can support real-world decisions, and how connected systems can communicate securely.

- ⚙️ **Data Engineering:** Designing data ingestion, transformation and analytics pipelines.
- 🤖 **Applied AI:** Exploring recommendation systems, retrieval-augmented generation and intelligent applications.
- 📡 **IoT & Communication:** Working with wireless communication, security and connected systems.
- 📊 **Data Platforms:** Exploring distributed processing, lakehouse architecture and analytics-ready datasets.
- 🚀 **Engineering Mindset:** Building, testing, refining and documenting practical solutions.

> My goal is to build systems that do more than work — they should be useful, reliable and scalable.
